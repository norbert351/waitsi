How it's real

  1. WAITSI returns HTTP 402 + a signed challenge for a sponsor top-up.
  2. A sponsor (or wallet) pays USDC on Base Sepolia to the rail address.
  3. WAITSI verifies the EIP-712 signature and the on-chain Transfer to payTo.
  4. It seeds the discovery budget from that verified asset-backed amount.
  5. Each settlement is appended to a hash-chained on-chain receipt (the VaultAnchor).
